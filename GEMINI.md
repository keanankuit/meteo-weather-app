# Gemini Project Instructions

## Project Overview
This is a Flutter-based Weather Application designed to explore the Flutter roadmap across Web, iOS, Android, and Desktop.

## Tech Stack
- **Framework:** Flutter
- **Design System:** Material 3
- **Platforms:** Android, iOS, Web, Windows, macOS, Linux

## Coding Standards
- Prefer `const` constructors for performance.
- Follow Effective Dart guidelines.
- Use Material 3 widgets and theme tokens.

## Interaction Rules
- **Do not edit files directly.** The user is learning and must perform all implementations manually.
- Focus on guidance, architectural explanations, and providing code snippets in the chat.
- Support the learning process by explaining the "how" and "why" of Flutter development.

## Common Commands
- Run app: `flutter run`
- Run tests: `flutter test`
